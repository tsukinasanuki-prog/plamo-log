# PLAMO LOG（OneDriveフォルダ共有版）

## 保存方式
- PCはWindows版ChromeまたはEdgeでOneDrive同期フォルダ内の `PLAMO_LOG_DATA` を選択します。
- 選択したフォルダに `PLAMO_LOG_DATA.json` を作成し、キット情報・日記・写真・注釈を含む全データを自動保存します。編集内容はブラウザ内のPCデータにも同時に自動保存します。
- 選択したフォルダ情報はブラウザ内に保持されます。次回起動時に許可が残っていれば自動でJSONを読み込みます。許可が必要な場合は右上の「OneDrive再接続（許可）」を押してください。保存済みフォルダのハンドルに対してクリック直後に権限要求を行うため、通常はフォルダを探し直す必要はありません。ブラウザの仕様上、起動のたびに許可ボタンを押す必要が生じる場合がありますが、フォルダ選択ダイアログとは別です。「別のOneDriveフォルダを選択」は保存先を変更するときだけ使います。
- PCでフォルダを選択した後、同じOneDrive同期フォルダを使う別PCでも同じ操作を行います。
- Androidは閲覧専用です。画面上部の「OneDrive JSON読込」を押し、OneDriveアプリ等から `PLAMO_LOG_DATA.json` を選択して読み込みます。更新を確認するときは再度読み込んでください。
- Microsoft Entra登録、Client ID、Microsoft Graph認証は使用しません。

## 初回設定（PC）
1. OneDrive内に `PLAMO_LOG_DATA` フォルダを作成します。
2. `index.html` をChromeまたはEdgeで開きます。
3. 「OneDriveフォルダ選択」を押し、作成したフォルダを選び、読み書きを許可します。
4. フォルダ内に `PLAMO_LOG_DATA.json` が作成されます。
5. OneDriveのJSONとPC内データの内容が異なる場合、アプリ内の最終保存日時を比較し、新しいほうを自動採用します。日時が同じ・不明など比較できない場合は、両方の更新日時と登録キット数を表示して選択できます。選んだデータはPC内とOneDriveの両方に保存されます。
6. 次回以降、許可が必要と表示された場合は右上の「OneDrive再接続（許可）」を押します。保存済みフォルダの許可を再取得するため、フォルダ選択は通常不要です。保存先を変更したい場合だけ「別のOneDriveフォルダを選択」を押します。

## 注意
- OneDriveの同期フォルダがPC上に実体として存在する必要があります。エクスプローラーでOneDriveの同期が完了してから別PCで起動してください。
- PCのブラウザがフォルダアクセスAPIに対応している必要があります。最新のChrome/Edgeを推奨します。`showDirectoryPicker` が利用できない環境では直接保存できません。
- Androidはファイル選択時点のJSONを読み込む方式で、常時同期・自動更新ではありません。Androidからの編集・保存は行いません。
- 写真データもJSON内に格納するため、写真が増えるとJSONが大きくなります。
- ブラウザのサイトデータを消去するとフォルダ許可情報が失われることがあります。その場合はフォルダを再選択してください。
- OneDriveへの書き込みに失敗した場合は画面上部に「OneDrive保存失敗」と表示します。PC内のデータは別に保持されます。
- データの比較には、アプリが記録する最終保存日時を使用します。旧バージョンのデータに日時情報がない場合は、JSONファイルの更新日時を補助的に使います。比較できない場合はユーザーに選択を求めます。
- 実運用前に、少数のテストデータでPC保存・別PC読込・Android読込を確認してください。


## Excelからの一括取り込み
- PCでOneDriveに接続した状態で、画面下部の「Excel記録を追加（84件）」を押します。
- 確認画面で続行すると、2冊のExcelから抽出した84件のキット記録と15件の塗料近似色データを追加します。
- 既存のアプリデータは削除・上書きしません。同じ名前でも別シートの記録は別々に残します。
- 取り込み済みのExcel記録には識別IDが付くため、同じボタンを再度押しても同じ記録は重複追加されません。
- Excelに正確な日付がない場合は日付を推測せず、元の時期表記を日記・基本情報に残します。開始・完成の時期が文字で記載されている場合は、製作状態にも反映します。
- Excelに記載のないメーカー・ジャンル・スケール・購入金額は未登録扱いです。ジャンルは初期値「その他」とし、必要に応じて編集してください。
- Excel内に埋め込み写真は確認できなかったため、写真は取り込まれません。
- 「塗料近似色」タブで、Mr.カラー・ファレホ・タミヤカラーの対応表を検索できます。
